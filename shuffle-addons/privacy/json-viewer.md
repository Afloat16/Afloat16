# 拾序JSON树隐私说明

发布者：[Afloat16](https://github.com/Afloat16) · 生效日期：2026年10月22日

## 输入与网页权限

扩展在本地解析你输入的 JSON、你主动选择的本地文件，以及你在目标网页点击扩展图标后，再按“读取目标页文本”取得的 `pre` 或正文文本。`activeTab` 和 `scripting` 权限只用于这项主动读取；没有全站常驻访问权限，不自动扫描或替换所有 JSON 网页。目标页标题和地址可能只在当前工具页显示。

## 保存与导出

JSON 原文、树和格式化预览只在当前工具页内存中处理，不自动持久保存。你主动使用高级导出时，浏览器将 JSON 文件保存到下载位置；文件可能含输入中的个人或业务资料。关闭工具或卸载扩展不会删除已下载文件，文件需由你另行保管和删除。

## 本地授权

扩展在自己的浏览器本地存储中保存随机安装标识，以及你主动输入并成功验证的高级授权码。随机值不是硬件指纹；当前零售授权不做硬件或安装标识强绑定。授权按产品通过包内公钥在本地核验，不联系授权服务器，也不上传 JSON、文件、网页原文、授权码或安装标识。

## 网络与删除

没有运营者遥测、广告、分析 SDK、云同步、远程 JSON 验证或自动网络上传。你主动打开 GitHub、发送邮件或另行购买时，由相应客户端或网站处理请求并适用其规则；扩展不会自动附加本地内容。

关闭工具页会释放原文和预览。清除扩展数据或卸载可删除本地安装信息及授权；“移除本地授权码”只清除该码，不会自动发起退款。重新安装或迁移按[个人单设备许可](../LICENSE.txt)执行，迁移前移除旧安装的授权。下载文件需另行删除。

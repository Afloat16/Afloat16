## Edge 开发模式安装

1. 完整解压交付 ZIP，保留解压后的目录。
2. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择包内 `edge/text-checker/` 目录；该目录中直接包含 `manifest.json`。
4. 不要选择整个 ZIP、解压根目录或 `edge/` 父目录。安装后不要移动或删除加载目录。
5. 从浏览器扩展菜单点击“拾序文字检查”图标打开工具。

这是保留解压目录的开发模式安装，不是 Edge 商店批准或上架证明。

## Firefox 临时开发加载

Firefox 版本已提交 AMO 审核，当前未保证批准或正式商店分发。交付包内 `firefox/text-checker/` 是**未签名开发文件，不是已签名 XPI**。

1. 解压后在 Firefox 打开 `about:debugging#/runtime/this-firefox`。
2. 点击“临时载入附加组件”，选择 `firefox/text-checker/manifest.json`。
3. 从扩展菜单点击工具图标。

重启 Firefox 后临时安装会移除。常规永久安装应等到已签名版本或正式 AMO 安装入口确认后使用；不需要为本工具关闭签名检查。

## 使用与 PRO

把文字输入或粘贴到工具页，点击“检查文字”，逐项查看并自行决定是否应用建议。修改原文后需要重新检查，旧建议不能直接套用。

当前最多60000字符、200项线索，涵盖重复英文词、少量固定英文拼写、空格与标点、重复中文标点及括号配对。可能误报；没有命中不代表全文正确。这不是 AI、通用拼写词典、完整语法或学术审校工具，也不会监听其他页面的输入。

PRO 可下载包含统计、问题位置、规则及建议片段的 JSON 报告。没有授权也能使用全部基础检查与手动建议。取得本产品授权后，打开“授权与升级”，粘贴授权码并点“验证并激活”。其他产品的码不能通用。

## What the projects do

### [Anti-REA Forge](https://github.com/Afloat16/anti-rea-forge)

Native release hardening with CMake integration, PE/ELF release gates, guarded C++ sensitive memory and request-bound authorization.

Version stated in README: **0.4.0 Alpha**; no published GitHub release.

### [Jev MCP](https://github.com/Afloat16/jev-mcp)

A TypeScript MCP server for bounded probabilistic advice, routing and risk signals, with cross-client installers.

Latest published GitHub release: [v0.5.0](https://github.com/Afloat16/jev-mcp/releases/tag/v0.5.0), 2026-09-28.

### [StewardCheck](https://github.com/Afloat16/ai-dev-steward)

Task-scoped Git change checks with StewardCheck and reproducible artifact/algorithm review.

### [Debate Direction](https://github.com/Afloat16/debate-direction)

Two-agent requirement debate with a Python CLI, issue tracking and explicit uncertainty.

### [LLM Handshake](https://github.com/Afloat16/llm-handshake)

Bounded OpenAI-compatible endpoint probes and report comparisons.

### [Bag Timeline Audit](https://github.com/Afloat16/bag-timeline-audit)

Read-only ROS 2 SQLite/MCAP timestamp diagnostics.

### [ReconTrail](https://github.com/Afloat16/recontrail)

CPU photogrammetry, photo-quality checks, sparse reconstruction, calibrated stereo and offline reports.

### [Research to Fix](https://github.com/Afloat16/research-to-fix)

Evidence-driven debugging workflow that maps prior solutions to local code and validates repairs.

### [SSE Toolcall Audit](https://github.com/Afloat16/sse-toolcall-audit)

Offline SSE tool-call assembly, completion and semantic comparisons.

### [TF Route Audit](https://github.com/Afloat16/tf-route-audit)

Offline TF topology and time-window checks, including native URDF.

### [Tooltrace Audit](https://github.com/Afloat16/tooltrace-audit)

Offline execution-trace checks for repeated attempts, overlapping retries and unmatched results.

### [ModelDock](https://github.com/Afloat16/modeldock)

Local 3D/CAD preview with bounded 5+ GiB binary PLY/STL sampling, multi-model alignment and reference comparison.

Latest published GitHub release: [v0.2.0](https://github.com/Afloat16/modeldock/releases/tag/v0.2.0), 2026-10-29.

Scope: 5+ GiB is bounded sampled preview of binary PLY/STL, not full rendering, huge CAD conversion, or a dense-file throughput benchmark. VS Code and DeepSeek Harness native acceptance reported; proprietary OpenAI Desktop native installation unverified.

### [Agent Action Notifier](https://github.com/Afloat16/agent-action-notifier)

Durable local/email notifications with SQLite tracking, retries and unverified reply review.

Latest published GitHub release: [v0.2.0](https://github.com/Afloat16/agent-action-notifier/releases/tag/v0.2.0), 2026-10-05.

### [COLMAP Model Audit](https://github.com/Afloat16/colmap-model-audit)

Read-only COLMAP text-model checks for tracks, cameras and view-graph consistency.

### [Pose Convention Bridge](https://github.com/Afloat16/pose-convention-bridge)

Explicit camera-pose conversion across coordinate conventions.

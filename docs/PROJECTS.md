## What the projects do

### [Anti-REA Forge](https://github.com/Afloat16/anti-rea-forge)

Seal native data with independently supplied keys and generated C++17/OpenSSL readers. Explore experimental LLVM 18 function virtualization and recorded analyzer controls.

Version recorded in the repository is **v0.10.0**. [Current README](https://github.com/Afloat16/anti-rea-forge/blob/11c5e5b0e19e311e06b86047bcd3da671e893817/README.md).

Externally keyed native data · Experimental LLVM 18 profiles.

### [ModelDock](https://github.com/Afloat16/modeldock)

Preview, align and compare meshes or point clouds locally. Explore sampled binary PLY/STL previews above 5 GiB and export comparison reports.

Version recorded in the repository is **v0.2.0**. [Published release](https://github.com/Afloat16/modeldock/releases/tag/v0.2.0).

Multi-model comparison · 5+ GiB sampled previews.

### [Jev MCP](https://github.com/Afloat16/jev-mcp)

Bring TypeSafe Jev advice to bounded choices, routing and risk checks through four MCP tools, with installers for multiple coding clients.

Version recorded in the repository is **v0.5.0**. [Published release](https://github.com/Afloat16/jev-mcp/releases/tag/v0.5.0).

Four stdio tools · Explicit bounded choices.

### [Bag Timeline Audit](https://github.com/Afloat16/bag-timeline-audit)

Find timestamp gaps, reversals and duplicates in ROS 2 SQLite or MCAP recordings, then compare topics using an explicitly shared clock.

SQLite + MCAP · Integer nanoseconds.

### [LLM Handshake](https://github.com/Afloat16/llm-handshake)

Probe OpenAI-compatible endpoints for streaming, tool calls and structured output. Preview exact requests and compare reports after a gateway or model upgrade.

Version recorded in the repository is **0.1.0**. [Current README](https://github.com/Afloat16/llm-handshake/blob/386c0d4e9f99309ab562d23589cd8725326eecfc/README.md).

Seven focused probes · Request preview.

### [ReconTrail](https://github.com/Afloat16/recontrail)

Check photo quality, reconstruct sparse 3D geometry on a CPU, and share a self-contained interactive report that opens offline.

Capture diagnostics · CPU sparse reconstruction.

### [TF Route Audit](https://github.com/Afloat16/tf-route-audit)

Check exported TF records and native URDF for cycles, disconnected frames and conflicting edges. Query routes against observed time windows.

Native URDF input · Topology diagnostics.

### [SSE Toolcall Audit](https://github.com/Afloat16/sse-toolcall-audit)

Reassemble parallel tool calls from saved SSE captures and check completion markers, JSON arguments and consistency with a saved final response.

Chat Completions + Responses · Parallel-call assembly.

### [Pose Convention Bridge](https://github.com/Afloat16/pose-convention-bridge)

Convert camera poses between OpenCV and OpenGL axes or world-to-camera and camera-to-world forms, with validated transforms and Nerfstudio export.

COLMAP + TUM inputs · Rigid-transform checks.

### [COLMAP Model Audit](https://github.com/Afloat16/colmap-model-audit)

Audit COLMAP text models for camera-field errors, broken reciprocal tracks and disconnected view graphs, with optional image-path and model-overlap checks.

Read-only model checks · Reciprocal track validation.

### [Tooltrace Audit](https://github.com/Afloat16/tooltrace-audit)

Review saved execution traces for overlapping retries, duplicate attempts and unmatched results. Add the optional recorder around your own tool calls.

Execution + conversation traces · Retry overlap checks.

### [Research to Fix](https://github.com/Afloat16/research-to-fix)

Research similar failures, map relevant solutions to your code and verify the repair. Save cases with source links and before-and-after evidence.

Source-backed diagnosis · Local applicability checks.

### [Debate Direction](https://github.com/Afloat16/debate-direction)

Let two agents propose, challenge and revise a plan. Keep the objections, remaining disagreements and next validation steps in a reviewable report.

Persistent proposer + critic · Issue ledger.

### [StewardCheck](https://github.com/Afloat16/ai-dev-steward)

Pin a task baseline, inspect edits against the agreed scope and keep test receipts tied to the files they actually checked.

Version recorded in the repository is **0.2.0 Alpha**. [Current README](https://github.com/Afloat16/ai-dev-steward/blob/f360968f7154c4b1e47ce622b11b114ba955f681/README.md).

Task-scoped Git checks · Workspace fingerprints.

### [Agent Action Notifier](https://github.com/Afloat16/agent-action-notifier)

Turn explicit workflow events into queued email or desktop alerts, with pending-request tracking, retries and recovery after interrupted delivery.

Version recorded in the repository is **v0.2.0**. [Published release](https://github.com/Afloat16/agent-action-notifier/releases/tag/v0.2.0).

SQLite outbox · Email + desktop channels.

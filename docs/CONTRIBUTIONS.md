### Craft Anything

**[#1340](https://github.com/storytold/craft-anything/pull/1340) — Decode concatenated Zstandard frames under one cumulative output limit** · merged 2026-11-09 20:17 · [`25a8f17`](https://github.com/storytold/craft-anything/commit/25a8f179f8b6b7730bc138fa8633180323c5d11c)

Processes each compressed frame until input is exhausted, skips length-framed skippable records and shares the same capped writer across all data frames.

The merged test decodes two valid frames around a skippable record, verifies exact output, enforces the combined byte limit and rejects truncated second or skippable frames.

Covers the bounded Zstandard decompressor used for archive members.

**[#1323](https://github.com/storytold/craft-anything/pull/1323) — Require a branch that rejects nonzero value before labeling an EVM dispatcher nonpayable** · merged 2026-11-09 20:15 · [`3f7b9a3`](https://github.com/storytold/craft-anything/commit/3f7b9a36158f7f732254051c0cc2df7832aec8d3)

Recognizes direct and inverted CALLVALUE guard patterns and follows the rejecting path. Limits a dispatcher-wide conclusion to a guard on its straight-line entry path.

Synthetic bytecode distinguishes a value read from a real rejecting guard, covers both branch directions and checks that a non-rejecting or unrelated path does not set a global nonpayable flag.

The bytecode analyzer recognizes bounded control-flow patterns. It does not execute contracts or establish a general proof of payability.

**[#1246](https://github.com/storytold/craft-anything/pull/1246) — Respect declared image and record boundaries during filesystem and archive recovery** · merged 2026-11-09 10:03 · [`b9a3525`](https://github.com/storytold/craft-anything/commit/b9a352542b640a78eaf3b63abf0409e8b399079c)

Limits cramfs directory reads, JFFS2 nodes, ROMFS images and SquashFS structures to their recorded extents and validates length-framed PAX metadata in tar archives.

Synthetic images exercise adjacent bytes, truncated nodes, empty directories, symlink budgets, partially retained extents and malformed PAX length boundaries.

The merged change covers five reader paths with synthetic recovery fixtures.

### DeepFace

The correction changes evaluation semantics and documented example metrics.

## Verification method

- GitHub’s public PR search for `author:Afloat16 is:pr is:merged` returned **71 results**, with `incomplete_results=false`, all on one page. Excluding 5 PRs in account-owned repositories leaves **66 merged PRs in 21 public upstream repositories**. Each indexed result has a merge timestamp. Counts include code, tests and documentation; they do not imply 66 bug fixes.
- Stars come from the official repository metadata API and belong to the upstream projects. They are a snapshot, not stars earned by my own repositories or a measure of contribution quality.
- Contributor positions come from the official public REST endpoint `/repos/{owner}/{repo}/contributors?per_page=100&anon=false`. GitHub sorts this list by commit contributions in descending order. The displayed number is its **one-based list position**, including bot accounts and excluding anonymous contributors. It is not a merged-PR ranking, maintainer role, lines-of-code ranking, or assessment of impact.
- Equal commit counts can occupy different positions. We retain GitHub’s returned order and require the actual list position to be ≤30; ties do not expand the cutoff. Contributor data may be cached for hours, and the API’s email-to-account matching has documented limits. Positions may differ from a chart that uses other filters.
- Only verified top-30 positions appear as ranks on the profile. If Afloat16 is absent from a requested first page, the exact rank and commit count remain unknown; absence is not reported as rank 101 or as proof of no contribution. The second group is therefore called “More merged upstream work.”
- The tables list verified top-30 placements first, then other merged work. Each group is sorted by stars descending. Individual PR links and the complete compact contributor lists are retained in the [machine-readable snapshot](contributions-2026-10-19.json).

Sources: [GitHub’s contributor-list API documentation](https://docs.github.com/en/rest/repos/repos#list-repository-contributors) · [Merged-PR search](https://github.com/search?q=author%3AAfloat16%20is%3Apr%20is%3Amerged&type=pullrequests).

This refresh verifies public contribution metadata. It does not rerun upstream test suites or broaden the original validation claims on the PRs. A representative change summarizes selected work in a repository, not every PR in it.
